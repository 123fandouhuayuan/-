# Codex 工作目录

此目录用于存放与 Codex 协作的独立代码、任务说明和项目文档，与仓库中的 `html18/` 平级。

## 使用约定

- 新的 Codex 协作内容默认放在本目录中。
- 除非任务明确要求，不修改 `html18/`。
- 不提交密码、API 密钥、真实数据库凭据或私有数据。
- 本目录暂不依赖 `html18/` 的 Python 环境或达梦数据库。

## 云端环境关联

在 Codex Cloud 环境中选择仓库 `123fandouhuayuan/-` 和分支 `master`。在环境准备说明中指定：

> 将仓库根目录下的 codex/ 作为任务工作目录。先阅读 codex/AGENTS.md。当前目录尚无运行依赖，不安装 html18/requirements.txt，不启动 html18 项目，不连接其数据库。后续根据 codex/ 中实际添加的项目文件配置依赖和验证命令。

创建本目录只是在 GitHub 中准备工作区，不会自动创建云端环境，也不会自动同步已有本地对话。

## 本机与云端协作

本机和云端通过 Git 提交、推送及拉取共享代码版本；本机未提交的文件不会因为关联了同一仓库而自动同步。
